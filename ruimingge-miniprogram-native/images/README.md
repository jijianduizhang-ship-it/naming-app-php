# 图标说明

此目录需要放置以下图标文件（尺寸建议 81x81px）：

- `home.png` - 首页图标（未选中）
- `home-active.png` - 首页图标（选中）
- `naming.png` - 起名图标（未选中）
- `naming-active.png` - 起名图标（选中）
- `history.png` - 记录图标（未选中）
- `history-active.png` - 记录图标（选中）
- `profile.png` - 我的图标（未选中）
- `profile-active.png` - 我的图标（选中）

## 临时方案

开发测试时，可以：
1. 使用微信开发者工具的占位图标
2. 或暂时注释掉 app.json 中的 tabBar 配置
3. 或使用简单的纯色PNG文件替代
